# Checklist

## 基础架构
- [ ] 项目目录结构创建完成，前后端项目可正常启动
- [ ] CORS 配置正确，前端可访问后端 API
- [ ] 后端日志系统可输出请求 ID、结构化字段、错误堆栈

## GPU 抽象层
- [ ] GPU 抽象层可正确检测 AMD/NVIDIA/Intel/CPU 并选择对应设备
- [ ] GPU 切换与 provider 选择的日志完整（型号、版本、显存）

## 音乐模块
- [ ] 音乐上传 API 支持 MP3/WAV/M4A/FLAC 格式，文件大小限制合理
- [ ] pychorus 高潮检测可自动识别歌曲高潮段落，返回起止时间
- [ ] 音频截取 API 可根据指定时间区间精确截取音频片段
- [ ] 音频波形数据 API 可返回前端可视化所需的波形数据

## 形象模块
- [ ] 形象上传 API 含人脸检测验证，拒绝无人脸的图片/视频
- [ ] 预设形象可正常加载和预览

## Wav2Lip-ONNX（默认模型）
- [ ] 后端已安装 `onnxruntime-directml` 与 `onnxruntime`（CPU 兜底）
- [ ] wav2lip.onnx 与 face_detection.onnx 权重文件已就位
- [ ] 推理接口 providers 顺序为 `[DmlExecutionProvider, CPUExecutionProvider]`
- [ ] 在 AMD 6700XT 上 DirectML EP 成功创建会话并完成推理
- [ ] DirectML 不可用时自动回退到 CPUExecutionProvider 并记录警告
- [ ] SadTalker 模型可成功加载并生成 3DMM 驱动的说话人脸视频
- [ ] LatentSync 模型可成功加载并生成扩散模型唇形同步视频

## 调度与 API
